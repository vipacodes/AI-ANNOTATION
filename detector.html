This is a mirror, not a verdict. It measures five surface features of text. It is not a model classifier, it cannot see how a text was produced, and it will be wrong often. Short text, translated text and writing by non-native English speakers all score badly here for reasons unrelated to how they were written — which is exactly why human-feedback platforms get false-positive accusations from their own tooling.
Run it on your own drafts, to learn which habits read as templated. Never run it on another person's work to accuse or screen them.

The tells bank

These are the phrases reviewers on contributor forums complain about, plus the ones that show up in every "how to avoid detection" thread. Density here is what moves the score most.

Counter-intuitive fact worth knowing: removing all of these and writing nothing else makes you look MORE automated, not less. Model output is detected by its evenness — uniform sentence length, no first person, no specifics — not by vocabulary. The fix is adding idiosyncrasy: an odd detail, a number only you would have, a short sentence next to a long one.
